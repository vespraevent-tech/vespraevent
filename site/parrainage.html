PARRAINAGE

Vous avez déjà loué chez nous ? Offrez 10 € à vos proches sur leur location — et gagnez 10 € à chaque fois.

  1. 1

    Vous créez votre code

    Votre nom et votre prénom suffisent. Le code est construit à partir de votre nom : il est à vous, et il ne change jamais.

  2. 2

    Vous le donnez autour de vous

    À vos proches, à vos collègues, au comité des fêtes. Ils le saisissent dans leur demande de devis et 10 € sont déduits, pour un panier d'au moins 40 €.

  3. 3

    Vous gagnez 10 € par filleul

    Dès que la location de votre filleul a eu lieu, 10 € sont déduits de votre prochaine location. Sans limite de nombre.

NOUS NE VOUS RETROUVONS PAS

Aucune location n'apparaît à ce nom. Le parrainage est réservé à nos clients : deux situations possibles.

Vous avez déjà loué chez nous

Votre location est peut-être enregistrée à un autre nom — celui de votre conjoint, de votre association ou de votre entreprise —, ou orthographié autrement. Appelez-nous, nous créons votre code avec vous :

Vous n'avez encore rien loué

On ne peut parrainer qu'après avoir été client : c'est ce qui donne du poids à votre recommandation. Après votre première location, revenez sur cette page — votre code vous attendra.

LES RÈGLES, EN CLAIR

  • Un code par personne. Il est construit sur votre nom et votre prénom, et reste valable sans limite de durée.
  • Remise valable dès 40 € de panier. En dessous, le code ne s'applique pas.
  • Autant de filleuls que vous voulez. Chacun a ses 10 €, et vous gagnez 10 € pour chacun d'eux.
  • Une seule remise par filleul. Le code joue sur sa première location, pas sur les suivantes.
  • On ne se parraine pas soi-même. Votre code ne s'applique pas à vos propres locations.
  • Vos 10 € sont acquis après l'événement. Nous les déduisons de votre location suivante ; une demande qui n'aboutit pas ne compte pas.
  • La remise ne se cumule pas avec une autre offre en cours sur la même location.

Une question sur le parrainage ? Écrivez-nous à contact@vespraevent.com ou appelez le 06 50 83 68 28. Nos conditions générales de location s'appliquent.
