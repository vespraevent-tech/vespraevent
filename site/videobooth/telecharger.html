Vespra Event

Télécharger l’application

Les applications se téléchargent avec un mot de passe, donné par Vespra Event. Une fois installées, elles s’ouvrent sans mot de passe.

Installation sur la tablette Android (une seule fois)

  1. Téléchargez le fichier depuis la tablette, avec le mot de passe ci-dessus.
  2. Sur Samsung, désactivez d’abord Auto Blocker (Réglages, Sécurité et confidentialité).
  3. Ouvrez le fichier et autorisez l’installation d’applications inconnues pour votre navigateur, puis touchez Installer.
  4. Ouvrez Vespra Vidéobooth, autorisez la caméra et le micro, puis choisissez-la comme application d’accueil et touchez Toujours.
