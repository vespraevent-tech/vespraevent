# Vespra Event — modifications v332

- Suggestions d'adresses dans le back-office et le formulaire public via la Base Adresse Nationale.
- Les adresses sélectionnées sont formatées sur 2 lignes : rue puis code postal + ville.
- Devis/factures : colonnes `PU HT`, `TVA`, `TOTAL TTC`.
- Acompte : calcul automatique à 30 % du total TTC ; aucun montant manuel à saisir.
- Devis : `Acompte à verser` puis `SOLDE À PRÉVOIR`.
- Facture : la case `Déduire un acompte déjà versé` reprend automatiquement 30 % si la réservation est marquée avec acompte.
