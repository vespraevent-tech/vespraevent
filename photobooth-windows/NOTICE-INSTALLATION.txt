VESPRA EVENT PHOTOBOOTH — INSTALLATION SUR UN MINI-PC (Windows 10/11)
=====================================================================

À faire une seule fois par photobooth (environ 20 minutes).

1. L'APPLI
   - Décompressez « Vespra-Event-Photobooth-Windows-1.1.0.zip » dans C:\VespraEvent\App
     (clic droit > Extraire tout).
   - Double-cliquez sur « Vespra Event Photobooth.exe ».
     Windows peut afficher « Windows a protégé votre ordinateur » (l'appli n'est pas
     signée) : cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
   - Au premier lancement : mot de passe d'accès des bornes (le même que le vidéobooth).
   - Démarrage automatique : l'appli s'inscrit toute seule au démarrage de Windows
     (réglable dans le menu > Général). Au rallumage du PC, elle rouvre le dernier
     événement lancé, en plein écran.
   - Conseillé : ouverture de session Windows automatique (sans mot de passe) et
     mises à jour Windows réglées hors des heures d'événement.

2. L'APPAREIL PHOTO CANON EOS 1300D (pilote intégré : aucun logiciel Canon ni digiCamControl)
   - Sur le Canon : mode M (réglez ouverture, vitesse, ISO une fois pour toutes), mise au
     point AF, extinction automatique désactivée (menu > Arrêt auto > Désactivé), batterie
     factice branchée, boîtier allumé, câble USB branché au PC.
   - UNE SEULE FOIS PAR PC (1 minute) : Windows donne le Canon à son propre pilote, que
     l'appli ne peut pas utiliser. Il faut lui donner le pilote USB libre « WinUSB » :
       a) Dans l'appli : menu > Paramètres de l'appareil photo > « Préparer l'appareil
          photo » (ouvre la page de l'outil libre Zadig). Téléchargez et lancez Zadig.
       b) Zadig : menu Options > « List All Devices ». Choisissez « Canon Digital Camera »
          (ou « EOS 1300D ») dans la liste. Choisissez « WinUSB » dans la case de droite.
          Cliquez « Replace Driver » (ou « Install Driver »), acceptez, attendez la fin.
       c) Éteignez puis rallumez le boîtier. Le nom « Canon EOS 1300D » doit s'afficher en vert.
     Remarque : après cette étape, les logiciels Canon (EOS Utility) ne voient plus
     l'appareil sur ce PC. Ce n'est pas un problème pour le photobooth.
   - Vérification : « Prendre une photo test » dans le même menu.
   - Repli : si vous préférez digiCamControl (webserver activé, port 5513), l'appli
     l'utilise automatiquement quand le pilote intégré n'a pas pu se connecter.

3. L'IMPRIMANTE DNP (DS620 ou RX1HS)
   - Installez le pilote DNP. Réglez l'imprimante en papier 10×15 (6x4).
   - Pour les bandelettes 5×15 : ajoutez la même imprimante une 2e fois dans Windows
     (Paramètres > Imprimantes > Ajouter, même port USB), renommez-la
     « DNP bandelettes » et réglez dans ses préférences la coupe 2 pouces
     (option « 2inch cut » ou format « 6x4 x2 » selon le pilote).
     L'appli imprime alors deux bandelettes sur une feuille 10×15, coupée en deux.
   - Dans l'appli : menu > Paramètres de l'appareil photo > choisir
     « Imprimante des photos 10×15 » et « Imprimante des bandelettes 5×15 ».

4. MENU DE LA BORNE
   - 5 appuis rapides (ou appui long de 3 s) dans le coin en haut à droite de l'écran
     d'accueil, code 0104.
   - Clavier (personnel) : Ctrl+Maj+K = quitter/remettre le plein écran,
     Ctrl+Maj+Q = fermer l'appli.

5. LES PHOTOS
   - Sur le PC : C:\VespraEvent\Photobooth\<nom de l'événement>\ (modifiable dans Général).
   - En ligne : back-office > Photobooth > l'événement > Tableau de bord.
   - Sans internet, la borne continue : les photos partent toutes seules au retour du réseau.
     (Il faut internet au tout premier lancement d'un événement.)
